LoadView

Task Manager's performance graphs, pinned to the corner of your screen.

A lightweight, always-on-top Windows overlay showing live CPU, GPU, RAM, disk and network graphs — plus temperatures, per-drive usage, top processes, a clock and your IP — as a single portable .exe. No install, no dependencies.

Windows 10 / 11 Free & open-source (MIT) No install Works with Memory Integrity

⬇ Download LoadView

A tiny, portable alternative to Rainmeter, Sidebar Diagnostics and heavyweight monitoring suites.

  • Everything at a glance — CPU / GPU / RAM / disk / network graphs, per-drive usage bars, top-5 CPU & RAM processes, LAN / WAN IP, clock, date and weekday.
  • Temperatures for every GPU (NVIDIA / AMD / Intel, no driver) plus an optional accurate CPU temperature that works even with Windows Memory Integrity on.
  • Vendor-neutral & DPI-agnostic — the same counters Task Manager uses; crisp at any scaling; remembers its position per screen resolution.
  • Fully configurable — resize, reorder or hide any section; per-graph colours, max and red alerts; MB/s or Mbps; °C/°F; opacity; always-on-top or coverable; lock.
  • Single portable exe — one LoadView.exe, runs on any Windows 10/11 PC.
